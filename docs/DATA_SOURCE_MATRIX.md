# Data source matrix

**Reviewed against the Groww curl and Python backtesting pages, the curl changelog, and the candle-interval annexure on 14 Oct 2026.** `GET /v1/historical/candles` is documented for CASH and FNO. Index examples are `NSE-NIFTY` and `BSE-SENSEX`. Fifteen-minute requests use `candle_interval=15minute` and are limited to 90 days. The timestamp format is `yyyy-MM-dd HH:mm:ss`. Timezone, bar start versus bar end, request inclusivity, partial candles, and session open and close behavior are unspecified. One authenticated NIFTY M15 request was sent for 13 Oct 2026 09:15–15:30. It returned 26 naive timestamps and remains quarantined. No second historical request was sent for the timestamp check. No independent 15-minute reference with a stated timestamp contract was available. M7.2 found no Groww support reply in the repository. The unanswered items are timezone, bar start versus bar end, request inclusivity, session open, session close, partial candles, and index timestamp behavior. Index volume and a research licence remain unverified. A later check fetched the curl backtesting page again on 14 Oct 2026 and found the same gap. NSE daily index files and paid NSE feeds do not supply a documented 15-minute NIFTY timestamp contract. On 14 Oct 2026 the Upstox V3, Kite Connect historical, Angel One historical, and DhanHQ intraday pages were also read. None of them supplies a NIFTY 15-minute contract with a stated timezone, a stated partial-candle rule, a named NIFTY index identifier, and a credential stored in this application. No trusted dataset was created and M2, M3, and M4 were not run on market history.

Access that would be required before another read: an enabled credential for a provider whose timezone, bar boundary, request bounds, session candles, and partial-candle rule are written by that provider; the NIFTY 50 index identifier from that provider; and a stated research-use permission. Costs are not stated on the fetched pages. The designed check is one completed session, then quarantine until those items are verified. It places no order.

A later read-only one-minute NSE-NIFTY response is also stored. It contains 31 offset-less timestamps from `2026-10-13T09:15:00` through `2026-10-13T09:45:00`, spaced 60 seconds apart, with numeric OHLC and null volume and open interest. Structural checks passed. For two complete windows, the 15-minute OHLC equals the one-minute rows that begin at the 15-minute timestamp and run for 15 minutes: 09:15 through 09:29, and 09:30 through 09:44. Treating those timestamps as the last minute of the bar does not match. That alignment is supporting evidence from these two files. It is not an official Groww statement of bar start, timezone, request inclusivity, session candles, or incomplete candles. Both records remain `UNVERIFIED_PROVIDER`. No trusted dataset was created. Training and walk-forward evaluation require a sealed dataset lineage record. A caller eligibility flag is not that record. Changing sealed source candles, detaching feature rows, or naming a quarantine file as the parent is refused before labels, fitting, or metrics. An explicitly declared synthetic series remains research data, with `real_market_data_verified` false. An exact copy of stored quarantine OHLC is still refused. A price that no longer matches is not inferred to be the same candle and is not marked verified. A paper simulation that is given a quarantined record is rejected before an intent or a fill is recorded.

A local read of the two stored quarantine files did not send a request. Each record checksum matches its own JSON. The complete record stores 26 offset-less timestamps from `2026-10-13T09:15:00` through `2026-10-13T15:30:00`, spaced 900 seconds apart, with numeric OHLC, null volume, and null open interest. The summary record cites the same provider-body SHA-256 and does not store the candle array. The original HTTP body is not in the file, so that SHA-256 cannot be recomputed. Expected session count, opening and closing candles, and request inclusivity stay undetermined. Structural consistency is not a trusted dataset.

Package named on the introduction page: `growwapi`. The curl introduction page, re-read for the integrations settings, documents three credential flows: a pasted access token that expires daily at 6:00 AM with no timezone stated; API key plus secret, exchanged at `POST /v1/token/api/access` with `key_type=approval` and a SHA-256 checksum of `secret + epoch seconds`; and API key plus a TOTP code, with `key_type=totp`. The Python page shows the TOTP code coming from `pyotp.TOTP(secret).now()`. Access-token generation is limited to 5/s, 30/min, and 150/24 hours. No authenticated call was made from this repository. The settings connection test, when an operator runs it, uses `GET /v1/margins/detail/user` and does not place an order.
